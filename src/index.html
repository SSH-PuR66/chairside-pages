A proposed path to a working pilot

1

Define the workflow

Agree on a bounded task and measure its current time and failure modes.

2

Configure integrations

Map fields, choose infrastructure, and establish access and operational ownership.

3

Test with your team

Use approved test data, simulate errors, and document manual recovery paths.

4

Evaluate before expanding

Compare observed results with the baseline before making a deployment decision.

Questions about this prototype

What works in the browser?

The calculator, mobile navigation, package selection, template previews, and JSON downloads run locally in the browser. The workflows are not executed by this site.

Are the templates ready to run?

They are illustrative n8n JSON examples with placeholder identifiers and incomplete integration settings. JSON parsing alone does not verify import or execution.

Where is the source?

The repository includes the page, calculator tests, and workflow examples. Review the source and dependency terms before adapting them.

Does this demo handle patient data?

No patient records or clinical systems are connected. The contact form sends a general project inquiry to Formspree; do not include patient information.
